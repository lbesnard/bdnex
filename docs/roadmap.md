# Roadmap

| Area | Status |
|---|---|
| Tag a file or folder from Bédéthèque (`bdnex -f`, `bdnex -d`) | available |
| Packaging with uv, wheel releases | available |
| Library database (files, albums, series, credits, cache) | available (Python API) |
| `bdnex import`: autotagger, duplicates, resume | planned |
| `bdnex ls`: query the library | planned |
| `bdnex write` / `move`: write tags, rename, convert | planned |
| Metadata source plugins | planned |

See [Library database](dev/library.md) for what is already in place.
